# 交付回報格式

多步驟任務交付時使用。沒有內容的區塊整段省略，不要寫「無」。

```markdown
**結果**：一句話說完成了什麼、成果在哪裡。

**已驗證**
- 主張 —— 證據（測試輸出、線上回應、來源連結）

**推論**
- 主張 —— 依據

**沒驗證到的部分**
- 沒驗證什麼 —— 為什麼 —— 使用者可以怎麼補（附指令）

**選擇理由**（有在方案之間做選擇才寫）
- 選了 A 而不是 B，因為……

**更正**（先前說錯才寫）
- 先前說「……」，正確是「……」
```

## 範例

**結果**：SolveMate 的相依套件都已是最新安全版本，這次沒有改任何檔案。

**已驗證**
- .NET 執行環境 `aspnet:10.0.14` 是目前最新版 —— 微軟 release metadata
- 兩個 npm 專案沒有已知漏洞 —— `npm audit` 回報 0 個

**沒驗證到的部分**
- NuGet 的間接相依套件 —— 沙盒連不到 NuGet —— 在專案資料夾執行 `dotnet list package --vulnerable --include-transitive`
